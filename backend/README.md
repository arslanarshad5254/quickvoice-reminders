# QuickVoice AI backend - cPanel deployment

Node.js API for secure AI reminder parsing. PostgreSQL stores installation metadata, AI prompts, structured responses, and request metrics. Safe repeated prompts are served from a per-installation cache before contacting the AI service.

## Requirements

- cPanel **Setup Node.js App** with Node.js 20 or newer.
- cPanel PostgreSQL Databases (or a remote PostgreSQL server).
- A domain or subdomain with HTTPS, such as `api.example.com`.
- Terminal/SSH access, or phpPgAdmin for importing migrations.

## 1. Upload safely

Upload the contents of this `backend` directory outside `public_html`, for example:

```text
/home/CPANEL_USER/quickvoice-backend
```

Do not upload `node_modules` or `.env`. cPanel installs dependencies on the server, and production secrets should be configured directly on the server.

## 2. Create the PostgreSQL database

In **cPanel -> PostgreSQL Databases**:

1. Create a database such as `quickvoice`.
2. Create a database user with a strong password.
3. Add the user to the database with all privileges.

cPanel normally prefixes both names with the account username. The connection URL therefore looks like:

```env
DATABASE_URL=postgresql://CPANEL_USER_dbuser:PASSWORD@localhost:5432/CPANEL_USER_quickvoice
DATABASE_SSL=false
```

Percent-encode special password characters when placing them in a URL.

## 3. Protect credentials

Create `/home/CPANEL_USER/quickvoice-backend/.env` from `.env.example`, set the actual database and AI credentials, and restrict its permissions:

```bash
chmod 600 /home/CPANEL_USER/quickvoice-backend/.env
```

## 4. Create the cPanel Node.js application

In **cPanel -> Setup Node.js App -> Create Application**:

- Node.js version: `20` or newer
- Application mode: `Production`
- Application root: `quickvoice-backend`
- Application URL: your HTTPS API subdomain
- Application startup file: `app.js`

Do not manually replace the `.htaccess` generated by cPanel/Passenger.

Click **Run NPM Install**, or activate the command shown by cPanel and run:

```bash
cd /home/CPANEL_USER/quickvoice-backend
npm ci --omit=dev
```

## 5. Apply migrations

From the activated Node.js environment:

```bash
cd /home/CPANEL_USER/quickvoice-backend
npm run migrate
```

Run the migration command after every deployment that adds a migration. Migration `002_remove_billing.sql` removes billing data created by an older backend version, and `003_ai_prompt_cache.sql` creates the prompt/response history and cache.

## 6. Start and verify

Restart the application from **Setup Node.js App**, then visit:

```text
https://api.example.com/health/live
https://api.example.com/health/ready
```

Both should return `{"status":"ok"}`. A `502` from `health/ready` means the PostgreSQL connection values or privileges are incorrect.

Opening the application URL itself returns a small JSON service status response. If you change cPanel environment variables, click **Save** and then **Restart** so Passenger launches a new process with those values.

Set the Android root `.env` to the final HTTPS URL and rebuild the app:

```env
BACKEND_BASE_URL=https://api.example.com
```

## API endpoints

- `GET /health/live`
- `GET /health/ready`
- `GET /`
- `POST /v1/ai/parse`

The POST endpoint requires the installation UUID supplied by the Android app in `X-Client-ID`.
